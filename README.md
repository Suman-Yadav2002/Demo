# Swiggy Sales & Business Performance Dashboard – Excel 📊

I'm excited to share my **Swiggy Sales & Business Performance Dashboard**, created in Microsoft Excel to analyze sales performance, customer ratings, orders, and business trends. 🚀

## Dataset Used
-<a href="https://github.com/Suman-Yadav2002/Demo/blob/main/Swiggy%20Dataset.xlsx">Dataset View</a>

## 📂 Dataset View

The dataset contains information related to Swiggy orders, restaurants, dishes, pricing, ratings, and locations.

## 📌 Project Overview

This interactive dashboard provides a consolidated view of Swiggy's sales performance and helps identify key business trends through dynamic visualizations and interactive filters.

## 📊 Key Insights at a Glance

✅ Total Sales: ₹53.01M  
✅ Total Orders: 197.43K  
✅ Rating Count: 5.59M  
✅ Average Rating: 4.34  
✅ Average Order Value: ₹268.51

- Monthly and weekly trends help track changes in sales performance.
- State and city-level analysis highlights geographical sales distribution.
- Food-type analysis provides an overview of sales contribution by category.
- Average Order Value helps understand customer spending patterns.
- Ratings and order metrics provide an overview of customer engagement and business performance.

The objective of this project is to transform raw sales data into an interactive Excel dashboard that makes it easier to monitor KPIs, identify trends, and support data-driven business decisions.
